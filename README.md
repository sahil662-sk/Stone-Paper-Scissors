# ✊ ✋ ✌️ Stone Paper Scissors — The Game Of Thronesss!

A sleek, responsive, and interactive browser-based Stone Paper Scissors game where you can battle against an intelligent bot.

🔗 **Live Demo:** [Play the Game Here](https://sahil662-sk.github.io/Stone-Paper-Scissors/)

---

## 📸 Preview

```text
       😎 YOU                     ⚡ VS ⚡                   🤖 BOT
  [ Score: 0 ]                                         [ Score: 0 ]
```

---

## ✨ Features

- **Player vs Bot:** Play against the computer in real-time.
- **Live Score Tracking:** Dynamically updates scores for both the player and the bot.
- **Move Display:** Visual showcase for both "Your Pick" and "Computer Pick".
- **Dynamic Status Messages:** Instant feedback on whether you won, lost, or tied the round.
- **Clean & Responsive UI:** Optimized for desktop and mobile screen sizes.

---

## 🎮 Game Rules

| Player Choice | Bot Choice | Outcome |
| :--- | :--- | :--- |
| **Rock (Stone)** | Scissors | **You Win!** (Rock crushes Scissors) |
| **Paper** | Rock (Stone) | **You Win!** (Paper covers Rock) |
| **Scissors** | Paper | **You Win!** (Scissors cut Paper) |
| *Same Choice* | *Same Choice* | **It's a Draw!** |

---

## 🛠️ Tech Stack

- **HTML5:** Semantic structure and layout.
- **CSS3:** Custom styles, modern cards, and responsive design.
- **JavaScript (Vanilla JS):** Game logic, randomized bot selection, and DOM manipulation.

## 🚀 Getting Started Locally

To run this project on your local machine:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/sahil662-sk/Stone-Paper-Scissors.git
   ```

2. **Navigate to the project folder:**
   ```bash
   cd Stone-Paper-Scissors
   ```

3. **Open `index.html`:**
   - Simply double-click `index.html` or open it in your favorite browser.
   - Alternatively, use the **Live Server** extension in VS Code.
